**What was fixed:**
- Source files: Removed all `require()` calls in favor of ESM imports
- Build: TypeScript compiles cleanly to `dist/`
- Runtime: Services now run with plain `node dist/...`
- Startup scripts: Updated to reference compiled paths
- package.json: Added `"type": "module"` for clean ESM execution
